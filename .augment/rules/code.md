Tiến hành và phân tích và giải thích chi tiết trước, khi nào người dùng oke mới tiến hành sửa code

## Tool cần dùng 

- Context7: cho việc lầy tài liệu và code snippet chính thức
- Code_research: để lấy code example từ các nguồn có sẵn
  Tìm kiếm trên các nguồn như github, stackoverflow

## Công việc thực hiện:

- Xác định thư viện, công nghệ chính của yêu cầu
- Dùng Context7 để tìm tài liệu chính thức
- dùng Code_research để tìm code example từ các nguồn
- Đọc lại toàn bộ codebase để nắm cấu trúc, pattern
- Xác định các file cần sửa đổi, thêm mới, xóa bỏ
- Tạo một thư mục mới tronf thư mục docs với tên là phase hiện tại sau đó đề xuất cấu trúc thư mục + file docs chi tiết trong thư mục đó,
- xin tôi duyệt trước khi bắt đầu tạo/sửa file. Sau khi tôi OK, mình mới tiến hành
